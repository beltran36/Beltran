¿Qué es el interés compuesto?

El interés compuesto permite que los rendimientos generen nuevos rendimientos, aumentando el capital de forma exponencial.

¿Cómo usar esta calculadora?

Introduce el capital inicial, la tasa anual, los años y la frecuencia de capitalización para ver el monto final.
